Go with gin framework
using MongoDb for database

1st package -> go get github.com/gin-gonic/gin -> to handle HTTP methods

2nd package -> go get github.com/joho/godotenv -> for env files

3rd package -> go get go.mongodb.org/mongo-driver/mongo -> Mongodb driver

4th package -> go get go.mongodb.org/mongo-driver/mongo/options

5th package -> go install github.com/air-verse/air@latest -> for live reloading [nodemon for nodejs]
